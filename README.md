
# Luma — искусственный язык Евгения Белоусова

Luma — это конланг (искусственный язык) с прозрачной морфологией и минималистичной фонетикой. Проект объединяет словарь, символику и музыку как единое культурное пространство.

---

## 📚 Словарь

`Vocabulary.md` — 1266 лексем (A–Z), версия 3.0.  
Правила словообразования:
- **-o** — существительное
- **-a** — прилагательное
- **-i** — глагол
- **-e** — наречие
- Множественное число: частица **ma**

Слова организованы по алфавиту с пояснениями значений. Словарь готов к расширению и автоматизированной обработке (подходит для тренажёров, парсеров, игр).

---

## 🏳️ Флаг любителей языка Luma

Официальный флаг — прямоугольное полотнище (2:3) из трёх горизонтальных полос:
- **Лазурный (верх)** — цвет истины.
- **Золотой (центр)** — цвет зрелой пшеницы; в центре — стилизованное солнце с 8 лучами и негативным пространством в середине (символ открытости).
- **Серебряный (низ)** — светлый серый с перламутровым отливом, символ мира и чистоты помыслов.

Флаг спроектирован с учётом печати: CMYK-значения подобраны под стандарт Coated FOGRA39.
